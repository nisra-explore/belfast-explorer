Data Explorer

About the Data Explorer

The NISRA Data Explorer is a tool that helps you find and use official statistics.

You can use it to explore, view and download data from the NISRA Data Portal.

It is designed to be simple to use. You do not need technical skills to get started.

What you can do

With the Data Explorer, you can:

  • Search for datasets
  • Filter data by topic, place or time
  • View data as charts, maps or tables
  • Download datasets
  • Export data for your own analysis

The NISRA Data Portal provides open, machine-readable data to support transparency, reuse, and innovation.

Key features

Live data

The Data Explorer connects directly to the NISRA Data Portal. This means you are viewing the latest available data.

Easy to explore

You can filter data by:

  • geography (for example local council or assembly area)
  • time (for example, year)
  • topic

You can view results in different ways, including charts, maps and tables.

Download data

You can download data in CSV format. This allows you to reuse it in other tools.

About the NISRA Data Portal

The NISRA Data Portal is where NISRA publishes its official statistics.

It contains datasets across seven themes:

  • People and communities
  • Health and social care
  • Work, pay and benefits
  • Education and skills
  • Transport, environment and climate change
  • Crime and justice
  • Business, economy and trade

The Portal provides open data. This means it can be reused by anyone.

Training and support

The Data Explorer is designed to make data easier to access. However, it may not meet all needs.

For more advanced use such as using APIs, you can go directly to the NISRA Data Portal.

We also provide a User Guide including video tutorials to help you use the Portal.

Feedback and development

The Data Explorer is a prototype. We are continuing to improve it.
